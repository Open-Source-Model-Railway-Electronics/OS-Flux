# OS-Flux

The OS-Flux is a tiny open-source DCC decoder built around an ATtiny85 with four LED/function outputs. It fits inside a signal housing or a locomotive.
Flashed with the Flux-Signal firmware it is a signal decoder that drives up to 4 signal lamps, steady or blinking, via DCC extended accessory commands or turnout commands.
Flashed with the Flux-Mobile firmware it is a locomotive function decoder with directional headlights and CV-configurable auxiliary outputs.
